# Project Statement

## Problem Statement
Most text based games are static and not much challenging but this game is an interactive haunted house escape game with turn limits, ghost risk challenge.

## Scope
This is a python based game with a fixed set of rooms,a turn limit, a collectible item, and finite number of possible endings i.e. win, ran out of time or caught by the ghost.

## Target users
Anyone who enjoys short, text based adventure games, or students learning Python.

## High-Level Features
- Room to room exploration
- Inventory system(pick up and use items)
- Turn limit
- Risk element (ghost room)
- Multiple endings
